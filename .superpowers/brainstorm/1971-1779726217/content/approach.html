Controle de Impressoras - Abordagem

Como organizar o card e o formulário no dashboard

A

Card no Dashboard + Modal Overlay

Card no dashboard (como "Solicitar Dados de Impressoras") que abre um modal overlay com a listagem, filtros, seleção e formulário. Botão "Gerar PDF" no rodapé do modal. Segue o padrão já existente do PrinterRequestCard e PreventiveMaintenanceCard.

B

Card no Dashboard + Página Dedicada

Card no dashboard que navega para uma página dedicada (/controle-impressoras). Mais espaço para a tabela de impressoras, filtros avançados e preview do PDF. Experiência mais completa mas exige rota nova.

C

Card no Dashboard + Drawer Lateral

Card no dashboard que abre um drawer lateral (slide-in da direita) com a listagem e formulário. Ocupa menos tela, permite ver o dashboard ao fundo, mas espaço mais limitado para a tabela.

Fluxo resumido

  1. Usuário clica no card "Controle de Impressoras"
  2. Abre listagem com todas as impressoras do banco
  3. Filtros por escola/setor + checkboxes para selecionar
  4. Dados pré-preenchidos do banco, mas editáveis
  5. Botão "Gerar PDF" produz documento limpo e moderno
